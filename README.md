# Ftpget

Программа для скачивания файлов по протоколам FTP, SFTP, HTTP с ведением базы скачанных файлов и контролем размера файлов.

### Особенности:
-  Работает с каталогами, содержащими большое (более сотни тысяч) количество файлов.
-  Копирует файлы рекурсивно обходя каталоги как с сохранением структуры каталогов так и без.
-  При необходимости ведет учет скачанных файлов.
-  Может запускаться с указанием параметров соединения как в командной строке, так и в конфигурационном файле.
-  В процессе закачки файла проверяет изменение его размера, что исключает появление не до конца скачанных файлов. Данная проблема характерна для ресурсов, где файлы начинают копироваться с другого сетевого ресурса и могут изменять свой размер в процессе передачи.
-  Для исключения вышеуказанной проблемы со своей стороны программа закачивает файлы во временный каталог, откуда потом переносит уже скачанный и проверенный файл в целевой каталог.
- Контролирует запущенный экземпляр, предотвращая двойной запуск через создание PID файла.
- Контролирует наличие свободного места на диске для предотвращения нештатной работы.
- Пытается определить тип FTP сервера для ускорения получения списка файлов и их размера.
-  Маска может включать элементы даты для уменьшения объема обрабатываемых файлов:
    -  %d - Текущий день.
    - %D - Текущий день и предыдущие 3 дня.
    - %m - Текущий месяц.
    - %M - Текущий и предыдущий месяц.
    - %y - Текущий год (2 последних цифры).
    - %Y - Текущий и предыдущий год (2 последних цифры).
    - %f - Текущий год (4 цифры).
    - %F - Текущий и предыдущий год (4 цифры).

В маске может быть что-то одно из %D %M %Y %F

### Параметры запуска

```
ftpget.py  SOURCE DESTINATION MODE {COPY, MOVE,  XCPY, XMOV, DELE, MKDB, NONE} [ ОПЦИИ ]

Позиционные аргументы:
  SOURCE              FTP откуда копируем
  DESTINATION         куда копируем
  MODE                Режим работы программы
                          COPY - копируем файлы
                          MOVE - переносим файлы
                          XCPY - копируем с перезаписыванием имеющихся файлов
                          XMOV - переносим с перезаписыванием имеющихся файлов
                          DELE - только удаляем файлы
                          MKDB - заносим имеющиеся в каталоге источнике файлы в БД
                          NONE - пустой прогон

Должны быть указаны либо SOURCE DESTINATION MODE либо конфигурационный файл.


Опции:
  -h, --help            показать эту справку и выйти
  -c CONFIG, --config CONFIG
                        Конфигурационный файл
  -n NAME, --name NAME  Имя эземпляра процесса. По умолчанию ftpget.
  -r, --recursive       Рекурсивное копирование с сохранением структуры каталогов
  -R, --no_create_dir   Рекурсивное копирование без сохранения структуры каталогов
  -t, --debug           Вывод служебных сообщений для отладки
  -T TIMEOUT, --timeout TIMEOUT
                        Таймаут при ошибке соединения
  --retries RETRIES     Количество попыток, 0 - бесконечно
  --log_limit LOG_LIMIT
                        Максимальное количество строк LOG файла, 0 - бесконечно
  -l LOG, --log LOG     Файл для записи лога
  -j --concurrency CONCURRENCY
                        Количество потоков закачки
  -D --database {DB,ORMDB,NODB}
                        База данных файлов
                        NODB - не вести базу файлов (по умолчанию)
                        DB - вести базу данных файлов в ini файле.
                        ORMDB - вести базу данных в произвольной БД.
--engine 
                        Строка инициализации БД формата 
                        dialect+driver://username:password@host:port/database

                        
  -P PIDDIR, --piddir PIDDIR
                        Каталог для размещения PID файлов
  -p, --passive         Пассивный режим
  --broken_size         На сервере сломана команда SIZE
  --port PORT           Порт сервиса в случае отличия от стандартного
  --tmpdir TMPDIR       Папка для временных файлов. 
                        Для исключения проблем связанных с недополучением файлов Рекомендуется размещать 
                        папку для временных файлов на той же файловой системе,   где находится целевой каталог.

```

### Формат ini файла

```
[Config]
NAM = test
SRC = ftp://demo:password@test.rebex.net/pub/
DST = ./test
ACT = XCPY
OTH = no_create_dir;concurrency=5;database=DB

[DB]
```

- NAM - имя экземпляра процесса. Должно быть уникально.
- SRC URL ресурса-источника.
- DST URL  целевого ресурса.
- ACT Метод работы.
- OTH Перечень опций (полное имя опции) через точку с запятой.

В Секции [DB] могут  находиться сведения о закачанных файлах. Она не предназначена для редактирования.


### Примеры использования

`ftpget -c config.ini`

`ftpget.py ftp://demo:password@test.rebex.net/pub/ /tmp/ftp/ COPY -R`

### Замечания
-- PID файл зоздается в указанном каталоге. Пока файл существует повторный запуск невозможен. В случае необходимости следует убедиться в отсутствии запущенного процесса и удалить файл вручную.
